## 二、系统架构 + 数据流（约 40 秒）

> **画面**：展示架构图

**讲解词**：

> 系统分四个模块，由小组成员分工完成：前端、爬虫、数据库、后端（含 AI 模块），我负责后端和 AI 模块。
>
> 整体数据流分四步：

```
① 爬取：前端 → NestJS spawn Python 爬虫 → ZOL → JSON stdout 返回
② 入库：用户预览确认 → NestJS stdin 传 JSON → save.py → MySQL
③ 展示：前端 GET API → ECharts 图表
④ AI：  用户提问 → 后端查数据库注入 LLM → OpenAI 兼容接口流式返回
```

> 关键设计：NestJS 通过 `child_process.spawn` 异步调用 Python，两者通过 JSON stdout/stdin 通信，各取所长、松耦合。

### 3.1 爬取 → 预览 → 入库（完整链路）

> **画面**：演示搜索"RTX 5070" → 预览面板 → 确认保存

**讲解词**：

> 以搜索"RTX 5070"为例。点击"开始爬取"后，前端调 `POST /api/crawl`，后端 Crawl 模块用 spawn 异步启动 Python 爬虫。

**核心代码**（切到 `server/src/crawl/crawl.service.ts` — `startCrawl`）：

```typescript
// 1. 生成 taskId，创建任务记录在内存 Map 中
const taskId = Date.now().toString(36) + Math.random().toString(36).slice(2, 6);
this.tasks.set(taskId, { taskId, status: 'running', result: null });

// 2. 异步 spawn Python 爬虫子进程，不阻塞
const proc = spawn(python, [this.crawlerPath, keyword, category, String(count), '--preview'], {
  env: { ...process.env, PYTHONIOENCODING: 'utf-8', PYTHONUTF8: '1' },
});

// 3. 收集 stdout 中的 JSON 输出
let stdout = '';
proc.stdout.on('data', (data) => { stdout += data.toString(); });

// 4. 进程结束后解析 JSON，更新任务状态
proc.on('close', (code) => {
  task.result = JSON.parse(stdout.trim());
  task.status = task.result.success ? 'completed' : 'failed';
});

return { taskId };  // 立即返回，前端轮询 GET /api/crawl/status/:taskId
```

> 爬虫端用 `requests` 库发 HTTP（绕过 Scrapy 默认 TLS 的反爬检测），正则提取价格，处理"万"单位转换。结果通过 JSON stdout 返回。

**核心代码**（切到 `crawler/zol_scraper/spiders/zol.py`）：

```python
# 品类 → ZOL 分类 ID 映射
SUBCATE_IDS = {'CPU': '28', 'GPU': '6', 'RAM': '3', 'MB': '5', 'SSD': '626'}

def start_requests(self):
    while collected < self.max_items and page <= 8:
        # 用 requests 库发 HTTP（绕过 Scrapy 默认 TLS 的反爬检测）
        resp = requests.get(
            'https://detail.zol.com.cn/index.php',
            params={'c': 'SearchList', 'subcateId': subcate_id, 'keyword': self.keyword, 'page': page},
            headers=HEADERS, cookies=COOKIES, timeout=15,
        )
        soup = BeautifulSoup(resp.text, 'lxml')
        for ul in soup.find_all('ul', class_='series_list'):
            for li in ul.find_all('li'):
                name = li.find('a').text.strip()
                # 正则匹配 ¥ 符号提取价格，处理"万"单位
                m = re.search(r'[¥￥](\d+\.?\d*)\s*(万)?', li.text)
                if m:
                    price = float(m.group(1))
                    if m.group(2) == '万': price *= 10000   # ¥2.44万 → 24400
                yield ProductItem(name=name, category=self.category, price=price, ...)
        page += 1
        time.sleep(0.5)  # 礼貌延迟
```

> 爬虫入口 `main.py` 采用策略模式：`--preview` 用 `PreviewPipeline` 只收集不写库，正式模式用 `ProductPipeline` 调 db.py 写入。由于 Python 3.14 + Scrapy 2.16 在 Windows 上 CrawlerProcess 会挂死，我们绕过了 Scrapy 进程管理，手动驱动 Spider → Pipeline 数据流。

**核心代码**（切到 `crawler/main.py`）：

```python
def run_spider(keyword, category, max_items, preview=False):
    spider = ZolSpider(keyword=keyword, category=category, max_items=max_items)

    if preview:
        pipeline = PreviewPipeline()     # 预览模式：只收集，不写库
    else:
        pipeline = ProductPipeline()     # 正式模式：调用 db.py 写入数据库

    for item in spider.start_requests():
        pipeline.process_item(item, spider)

    return _collected_results
```

> 爬取结果先在预览面板展示，用户确认后才写入数据库。这里有个重要设计：数据通过 **stdin 管道**传给 `save.py`，而不是命令行参数——避免长度限制和 shell 转义问题。

**核心代码**（切到 `server/src/crawl/crawl.service.ts` — `confirmSave`）：

```typescript
async confirmSave(category: string, products: Array<{...}>): Promise<any> {
  const proc = spawn(python, [this.savePath, category], { ... });

  // 通过 stdin 管道传入 JSON（不用命令行参数：避免长度限制和转义问题）
  proc.stdin.write(JSON.stringify(products));
  proc.stdin.end();

  proc.on('close', (code) => {
    const result = JSON.parse(stdout.trim());  // Python 返回写入结果
    resolve(result);
  });
}
```

> Python 端 `save.py` 从 stdin 读取 JSON，调用 `db.py` 写入 MySQL。

**核心代码**（切到 `crawler/db.py`）：

```python
def upsert_product(name, category, spec='', url='', image_url=''):
    """插入或更新产品 — UPSERT 语义，防重复"""
    cursor.execute('''
        INSERT INTO products (name, category, spec, manmanbuy_url, image_url)
        VALUES (%s, %s, %s, %s, %s)
        ON DUPLICATE KEY UPDATE                        -- 存在就更新，不存在就插入
            spec=VALUES(spec), manmanbuy_url=VALUES(manmanbuy_url), image_url=VALUES(image_url)
    ''', (name, category, spec, url, image_url))
    conn.commit()

def insert_price(product_id, price, source='zol'):
    """记录价格，同一天已有记录则跳过"""
    cursor.execute('''
        SELECT id FROM price_history
        WHERE product_id = %s AND DATE(recorded_at) = CURDATE()   -- 按天去重
        LIMIT 1
    ''', (product_id,))
    if cursor.fetchone():
        return  # 今天已有记录，跳过
    cursor.execute('''
        INSERT INTO price_history (product_id, price, source) VALUES (%s, %s, %s)
    ''', (product_id, price, source))
    conn.commit()
```

### 3.2 数据展示（API → 前端）

> **画面**：产品列表 + 筛选排序 + 点击产品看价格趋势图

**讲解词**：

> 数据入库后，前端调 `GET /api/products` 加载列表，支持品类筛选、模糊搜索、多维度排序。

**核心代码**（切到 `server/src/products/products.service.ts`）：

```typescript
async findAll(category?: string, search?: string, sort?: string) {
  let sql = `SELECT p.*, ph.price as latest_price, ph.recorded_at as updated_at
    FROM products p
    LEFT JOIN price_history ph ON ph.id = (
      SELECT MAX(ph2.id) FROM price_history ph2 WHERE ph2.product_id = p.id  -- MAX(id) 取最新
    ) WHERE 1=1`;

  if (category && category !== 'ALL') { sql += ' AND p.category = ?'; params.push(category); }
  if (search && search.trim()) { sql += ' AND p.name LIKE ?'; params.push(`%${search.trim()}%`); }
  // 支持按时间、名称、品类、价格排序
  switch (sort) {
    case 'price_asc':  sql += ' ORDER BY latest_price ASC'; break;
    case 'price_desc': sql += ' ORDER BY latest_price DESC'; break;
    default:           sql += ' ORDER BY p.created_at DESC';
  }
  return this.em.query(sql, params);
}
```

> 为什么用 `MAX(id)` 而不是 `MAX(recorded_at)`？同一秒可能插入多条价格记录，`MAX(recorded_at)` 会返回重复行，而 `id` 自增主键保证唯一性。
>
> 点击产品查看价格历史，SQL 用 `GROUP BY DATE(recorded_at)` 按天去重，确保图表每天只有一条。

**核心代码**（切到 `server/src/products/products.service.ts` — `getPriceHistory`）：

```typescript
async getPriceHistory(productId: number, days: number = 30) {
  return this.em.query(`
    SELECT ph.price, ph.recorded_at FROM price_history ph
    INNER JOIN (
      SELECT DATE(recorded_at) as day, MAX(recorded_at) as max_time
      FROM price_history
      WHERE product_id = ? AND recorded_at >= DATE_SUB(NOW(), INTERVAL ? DAY)
      GROUP BY DATE(recorded_at)     -- 每天只取一条
    ) grp ON ph.recorded_at = grp.max_time
    WHERE ph.product_id = ?
    ORDER BY ph.recorded_at ASC
  `, [productId, days, productId]);
}
```

### 3.3 统计分析（Stats 模块）

> **画面**：展示仪表盘四个统计卡片

**核心代码**（切到 `server/src/stats/stats.service.ts`）：

```typescript
async getOverview() {
  const categories = await this.em.query(`
    SELECT category, COUNT(*) as product_count,
      ROUND(AVG(latest.price), 2) as avg_price,
      MIN(latest.price) as min_price,
      MAX(latest.price) as max_price
    FROM products p
    JOIN (
      SELECT product_id, price
      FROM price_history ph1
      WHERE id = (SELECT MAX(id) FROM price_history ph2 WHERE ph2.product_id = ph1.product_id)
    ) latest ON p.id = latest.product_id
    GROUP BY category
  `);
  return { categories };
}
```

> 先用子查询取每个产品的最新价格，再按品类 `GROUP BY` 聚合出数量、均价、最低、最高。

```typescript
const PRESET_PROMPTS = {

  compare: { name: '产品对比', content: '你是硬件产品对比分析师。从价格、性能口碑、价格趋势、性价比等维度比较...' },
};

// AI 对话核心：三步走
async chat(message: string, mode: string = 'query') {
  const context = await this.buildContext(message);     // 1. 查数据库，匹配相关产品
  const prompt = PRESET_PROMPTS[mode] || PRESET_PROMPTS.query;  // 2. 取预设提示词

  const response = await this.getProvider().chat([      // 3. 调 OpenAI 兼容 API
    { role: 'system', content: `${prompt.content}\n\n数据库数据:\n${context}` },
    { role: 'user', content: message },
  ]);
  return { reply: response, mode };
}
```

> AI 回答前查数据库获取相关产品数据，注入到 LLM 提示词中。所以回答基于**真实数据**，不是 LLM 的训练数据。

**核心代码**（切到 `server/src/ai/ai.service.ts` — `buildContext`）：

```typescript
private async buildContext(message: string): Promise<string> {
  const products = await this.em.query('SELECT id, name, category FROM products');

  // 匹配用户消息中提到的产品名或品类
  const matched = products.filter((p) =>
    message.includes(p.name) || message.includes(p.category)
  );

  if (matched.length === 0) {
    // 没匹配到 → 返回最近 50 条价格记录作为兜底
    return JSON.stringify(await this.em.query(`... ORDER BY recorded_at DESC LIMIT 50`));
  }

  // 匹配到了 → 只查这些产品的价格历史
  const ids = matched.map(m => m.id);
  const data = await this.em.query(`
    SELECT p.name, p.category, ph.price, ph.recorded_at FROM products p
    JOIN price_history ph ON p.id = ph.product_id
    WHERE p.id IN (${ids.join(',')}) ORDER BY ph.recorded_at DESC LIMIT 200
  `);
  return JSON.stringify(data);
}
```

> 采用 OpenAI 兼容接口，用户填入 DeepSeek、通义千问等国内模型的 API 地址也能用，支持 SSE 流式输出打字机效果。

**核心代码**（切到 `server/src/ai/providers/openai.provider.ts` — SSE 流式解析）：

```typescript
async *chatStream(messages, options?): AsyncGenerator<StreamChunk> {
  const resp = await fetch(`${this.baseUrl}/chat/completions`, {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${this.apiKey}` },
    body: JSON.stringify({ model: this.model, messages, stream: true }),
  });

  const reader = resp.body.getReader();
  let buffer = '';
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += new TextDecoder().decode(value, { stream: true });

    for (const line of buffer.split('\n')) {
      if (!line.startsWith('data:')) continue;
      if (line.includes('[DONE]')) { yield { type: 'done', text: '' }; return; }
      const parsed = JSON.parse(line.slice(5));
      const delta = parsed?.choices?.[0]?.delta;
      if (delta?.content) yield { type: 'content', text: delta.content };
    }
  }
}
```
